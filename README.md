# Programming Advices - Problem Solving

This repository contains a collection of C++ programming exercises and solutions inspired by ProgrammingAdvices.com. It was created as a personal learning archive for practicing problem solving, understanding core programming concepts, and improving coding skills.

## About the Project

The goal of this repository is to strengthen logic, build confidence in writing clean C++ code, and solve a variety of beginner-to-intermediate programming problems. Each file reflects a different exercise or concept, from arrays and vectors to conditions, loops, functions, and basic algorithms.

## How to Run

1. Open any C++ source file in a compiler environment or IDE.
2. Compile it using `g++`.
3. Run the generated executable.

Example:

```bash
g++ filename.cpp -o output
./output
```
